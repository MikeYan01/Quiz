## Agent skills

### Issue tracker

Issues and specs are tracked as local Markdown under `.scratch/`; never commit that directory, and remove completed feature folders after implementation. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with a root `CONTEXT.md` and system-wide ADRs under `docs/adr/`. See `docs/agents/domain.md`.
