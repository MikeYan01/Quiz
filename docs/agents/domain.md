# Domain Docs

This is a single-context repository.

## Before exploring

- Read the root `CONTEXT.md` for the domain glossary.
- Read relevant system-wide decisions under `docs/adr/`.
- If either location is absent, proceed silently.

## Vocabulary

Use canonical terms from `CONTEXT.md` in issues, specifications, tests, and implementation. Do not drift to synonyms listed under `_Avoid_`. If a required concept is missing, reconsider the terminology or flag the gap for `/domain-modeling`.

## Decisions

Surface conflicts with an existing ADR explicitly rather than silently overriding it.
