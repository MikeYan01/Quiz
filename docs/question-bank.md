# 题库

`public/data/knowledge-35000-v1/` 是项目唯一的题库事实来源。

```text
public/data/knowledge-35000-v1/
├── manifest.json
└── shards/
    ├── natural-science-001.json
    ├── math-logic-001.json
    └── ...
```

- `manifest.json` 记录题库版本、知识截止日、十个主类别的题目数、分片路径和 SHA-256 校验值。
- 每个分片直接保存浏览器需要的题目标识、题干、四个选项、正确答案、主类别和主题标签。
- 每个分片最多保存 50 题，避免开始挑战时为每个类别下载大量未使用题目。
- 首页加载后会缓存清单，并在浏览器空闲时预取首局所需的十个分片。
- 当前版本共 35,000 题，每个主类别 3,500 题。
- 应用和自动测试都直接读取这份题库，不存在 JSONL、开发夹具或审核数据副本。

## 扩容

生成新题时可以在会话临时目录中使用草稿文件，但草稿不进入仓库。完成结构检查和去重后，直接产生一个新的不可变 `public/data/<version>/`；切换应用版本并验证后，删除旧版本和全部临时草稿，始终只保留一个题库目录。
